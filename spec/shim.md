# SHIM — host requirements, v0 (draft)

The SHIM (SBL Hardware Interface Manifest) is generated by sloth from the same resolution
that produces an app's C++ config headers. Its schema is owned by `sbl-schema` in
sound-byte-libs (ADR-006); this document states what a host needs from it.

A host MUST be able to read, for each port: `id` (equal to the generated handle name),
`kind` (`analog_in|analog_out|digital_in|digital_out|midi_in|midi_out`), and for analog
ports `electrical.range_v`, `electrical.bits`, `electrical.inverted` and `idle_v`. For
audio: `in`, `out`, `sample_rate`, `block_size`, `format` (`s24_rj_i32`).

`shim_version` is independent of `protocol_version`; a host declares which SHIM versions it
reads. The host computes `sha256` over the SHIM file bytes and compares it with the
client's `hello.shim_sha256`.
